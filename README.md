

<h1>Interviewr</h1>

<p>
A <b>real-time collaborative coding interview platform</b> where developers can create coding sessions, invite participants, and conduct live problem-solving interviews with integrated <b>video calls and chat</b>.
<br/><br/>
The platform simulates a <b>technical interview environment</b>, allowing users to practice coding interviews, collaborate, and communicate seamlessly.
</p>


<p>

🔗 <b>Live Application</b> <br/> <a href="https://interviewr-one.vercel.app/">
https://interviewr-one.vercel.app/ </a>

</p>

<h2 align=>🎬 Platform Workflow</h2>

<p align="center">

1️⃣ User logs in<br>
2️⃣ Host creates a coding session<br>
3️⃣ A unique video call is created<br>
4️⃣ Participant joins the session<br>
5️⃣ Video call + chat start instantly<br>
6️⃣ Interview session happens in real-time<br>
7️⃣ Host ends session → marked <b>completed</b>

</p>
